# Implementation Plan: File Preview on the Create Form

**Spec**: [`spec.md`](spec.md)

## Summary

`CreateEntityItemContainer` keeps which file field is previewed and whether the narrow-screen dialog is open. It renders `CreateEntityItemFilePreview` in a side panel beside the form from the `split:` breakpoint (1200 px) up, or in a dialog below it; it mounts only one of the two. The preview reuses the content-focus preview pieces through the `entity-item` entry point: `ContentPreviewFrame`, `ContentAttributeOptionSelector` and `FilePreview`, which shows the picked `File` with `PdfPreview` or `ImageVideoViewer`; nothing is fetched. The container tells the form where the preview is with one `filePreview` value (`HalFormsFilePreview`): `dialog` with `onOpen`, or `beside` with `previewedFieldName`; a form without a file field gets none and keeps its layout. `HalFormsContainer` turns it into plain props for each field (`onFilePreview`, `previewed`, `compact`), so only the file fields whose highlight changes re-render. With the preview beside it, the form fills its height: only the fields scroll and the actions stay in view. The `pdf-viewer` pattern gains a password prompt.

## Layering

```
entity-item/variations/content-focus/
  file-preview                   FilePreview -> PdfPreview, ImageVideoViewer
                                 -> @contentgrid/navigator-data nativePreviewKind

entity-item-create/
  create-entity-item-container   owns previewFieldName, isPreviewOpen, isNarrow (useMediaQuery);
                                 renders the preview in an aside beside the form, or a Dialog
  create-entity-item-file-preview  field selector + the picked file's preview
                                   -> ../entity-item (ContentPreviewFrame,
                                      ContentAttributeOptionSelector, FilePreview)
  create-entity-item-form        -> ../hal-forms HalFormsContainer (filePreview)

hal-forms/render/
  hal-forms-container            filePreview -> each field's onFilePreview, previewed, compact
  hal-forms-field-renderer       onFilePreview, previewed, compact -> FileRenderer onPreview,
                                 previewed, compact

@contentgrid/ui
  hooks/use-media-query          matchMedia hook + SPLIT_BREAKPOINT_QUERY
  patterns/file-upload-zone      onPreview, previewed, compact, fill; Preview and Remove are
                                 ToolbarIconButtons
  patterns/form-renderers/file-renderer  forwards onPreview, previewed, compact
  patterns/pdf-viewer            password prompt; PdfLoadError kinds "invalid" | "engine"
  styles/preset.css              --breakpoint-split
```

## Files

**`packages/ui`**

- `src/hooks/use-media-query.ts` (new: `useMediaQuery`, `SPLIT_BREAKPOINT_QUERY`), exported from `src/index.ts`. The shadcn-generated `use-mobile.ts` stays as it is: it is fixed to the sidebar's 768 px breakpoint and is regenerated by the shadcn CLI. `SPLIT_BREAKPOINT_QUERY` repeats `--breakpoint-split`, as a media query in JavaScript cannot read a Tailwind theme value.
- `src/styles/preset.css`: `--breakpoint-split: 75rem`
- `src/patterns/file-upload-zone/file-upload-zone.tsx` (+ stories `Compact`, `Previewed`, `WithPreviewButton`): the Preview and Remove buttons are `ToolbarIconButton`s, so both carry a tooltip
- `src/patterns/toolbar-icon-button.tsx`: doc covers any row of icon actions, not only toolbars
- `src/patterns/form-renderers/file-renderer.tsx`
- `src/patterns/pdf-viewer/pdf-viewer.tsx`: `PdfViewerPasswordForm`; `onLoadError` reports `invalid` only
- `src/patterns/pdf-viewer/use-pdf-viewer-document-lifecycle.ts`: `passwordRejected`, `unlock`
- `src/patterns/pdf-viewer/pdf-viewer-labels.ts`: `passwordInput`, `passwordSubmit`, `passwordIncorrect`
- `src/patterns/pdf-viewer/pdf-viewer-toolbar.tsx`: Download stays enabled for a protected document

## Tests

- `create-entity-item-container.test.tsx`: preview follows the picked field and the focused field; unreadable PDF; continuous-create reset; highlight only with several file fields; read-only field's empty preview; narrow-screen dialog on the clicked field; the dialog closes on widening and doesn't reopen.
- `pdf-viewer.test.tsx`: `useDocumentLifecycle` reopens with the password and flags a wrong one; the password form flags a rejected password.
- `pdf-viewer.composition.test.tsx`: an invalid document is reported once; a protected one is not reported.
- `content-preview-panel.test.tsx`: a viewer-reported invalid PDF shows the corrupted message.
- `file-preview.test.tsx`: a picked image is shown; a type without a preview is named; an unreadable PDF can't be displayed; picking another file drops a load error.
- `use-media-query.test.ts`: follows the media query as it changes; stops listening on unmount.
- Visual baselines: `Patterns/FileUploadZone` `Compact`, `FileSelected`, `LargeFileSelected`, `Previewed`, `WithPreviewButton`; `Patterns/FormRenderers/FileRenderer` `FileSelected`; `Patterns/PdfViewer` `Protected`, `Invalid`.
